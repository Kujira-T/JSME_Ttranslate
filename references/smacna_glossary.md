# SMACNA 暖通与钣金工程术语对照表 (HVAC Duct Construction Glossary)

本词汇表针对 SMACNA 系列标准（尤其是 ANSI/SMACNA 006、ANSI/SMACNA 016 等）中的高频规范术语与专用缩写。

---

## 1. 风管构造与板材 (Duct Construction & Sheet Metal)

| 英文原词 (English) | 规范中文译名 (Chinese) | 行业释义 / 说明 |
| :--- | :--- | :--- |
| **Duct / Air Duct** | 风管 / 通风管道 | 空调、送风、排风管道系统 |
| **Rectangular Duct** | 矩形风管 | 传统四方风管 |
| **Round Duct / Spiral Duct** | 圆形风管 / 螺旋风管 | 螺旋卷制或纵焊圆形风管 |
| **Flat Oval Duct** | 扁椭圆风管 | 节省吊顶净高的扁圆风管 |
| **Sheet Metal Gauge (ga.)** | 板材号数 / 钣金厚度规 | 美制钢板厚度单位（如 24 ga = 0.7mm, 18 ga = 1.2mm） |
| **Galvanized Steel Sheet** | 镀锌钢板 | 常用空调风管材质 |
| **Stainless Steel Sheet** | 不锈钢板 | 腐蚀性排风或高洁净环境使用 |
| **Flexible Duct** | 柔性软管 / 铝箔复合保温软管 | 支管连接风口常用的柔性风管 |

---

## 2. 咬口与接头形式 (Joints & Seams)

| 英文原词 (English) | 规范中文译名 (Chinese) | 行业释义 / 说明 |
| :--- | :--- | :--- |
| **Transverse Joint** | 横向接头 / 横向咬口 | 连接两节风管的周向接头 |
| **Longitudinal Seam** | 纵向接缝 / 纵向咬口 | 风管管体自身的顺长接缝 |
| **Pittsburgh Lock** | 匹兹堡咬口 / 联合角咬口 | 矩形风管最常见的高气密纵向咬口 |
| **Snap Lock** | 按扣式咬口 / 插扣式咬口 | 组装便捷的自锁咬口 |
| **Slip and Drive (S & D)** | 插条与按条接头 (S码/C码) | 传统插接式风管横向连接方式 |
| **TDC (Transverse Duct Connector)** | 机制法兰 / 整体式横向法兰 | 风管板材直接冷弯压出的法兰边 |
| **TDF (Transverse Duct Flange)** | 共板法兰 | 与 TDC 类似的一体成型共板式法兰 |
| **Companion Angle Flange** | 贴角法兰 / 角钢法兰 | 额外焊接或铆接的角钢加固法兰 |

---

## 3. 加固、支吊与静压等级 (Reinforcement, Supports & Pressure Classes)

| 英文原词 (English) | 规范中文译名 (Chinese) | 行业释义 / 说明 |
| :--- | :--- | :--- |
| **Stiffener / Reinforcement** | 加固肋 / 加劲件 | 防止大截面风管负压凹陷或正压鼓包的角钢/型钢 |
| **Intermediate Reinforcement** | 中间加劲肋 | 位于两个横向法兰之间的管体加固件 |
| **Tie Rod / Internal Tie** | 内部拉杆 / 撑杆 | 风管内部跨接以承受风压的拉杆加固 |
| **Hanger / Support** | 吊架 / 支吊架 | 丝杆、扁铁或抱箍等支吊承载结构 |
| **Static Pressure Class** | 静压等级 | 风管承受的最大工作压强（如 $\pm 2$ in. wg, $\pm 4$ in. wg） |
| **Water Gauge (in. wg)** | 英寸水柱 | 压力单位（$1\text{ in. wg} \approx 249.08\text{ Pa}$） |
| **Leakage Class (CL)** | 漏风等级 (CL) | SMACNA 漏风分类（如 CL 3, CL 6, CL 12, CL 24） |
| **Aerosolized Duct Sealant** | 气溶胶喷涂密封胶 | SMACNA 第 4 版新纳入的风管内微粒自密封工艺 |
