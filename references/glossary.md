# 国际暖通、风管及海上工程标准术语对照表 (DW/144, DW/143, ISO 15138, ASTM)

本词汇表汇集 BESA DW/144、DW/143、ISO 15138（海上平台 HVAC）及 ASTM 材料标准中的高频核心术语。

---

## 1. BESA DW/144 金属风管制造与安装术语

| 英文原词 (English) | 规范中文译名 (Chinese) | 行业释义 / 说明 |
| :--- | :--- | :--- |
| **Ductwork / Air Duct** | 风管系统 / 通风管道 | 送风、排风、回风管道总称 |
| **Rectangular Duct** | 矩形风管 | 传统四方风管 |
| **Circular Duct / Spiral Duct** | 圆形风管 / 螺旋风管 | 卷制或直缝圆形风管 |
| **Flat Oval Duct** | 扁椭圆风管 | 适用于净高受限区域的扁圆截面风管 |
| **Class A (Low Pressure)** | A 级（低压系统） | 允许最高正压 500 Pa，最大风速 10 m/s |
| **Class B (Medium Pressure)** | B 级（中压系统） | 允许最高正压 1000 Pa，最大风速 20 m/s |
| **Class C (High Pressure)** | C 级（高压系统） | 允许最高正压 2000 Pa，最大风速 40 m/s |
| **Class D (High Negative/Positive)**| D 级（极高压/超高压） | 允许最高正压 2500 Pa / 负压 750 Pa |
| **Slide-on Flange** | 插接法兰 / 滑入式法兰 | 常见如 Mez, Doby, Verrolec 等机制卡入式角码法兰系统 |
| **Mastic / Sealant** | 密封胶 / 嵌缝密封剂 | 法兰面及咬口缝隙填充胶 |
| **Stiffener / Stiffening Angle** | 加劲肋 / 加固角钢 | 防止管壁在正负压下产生挠度变形的加固件 |
| **Tie Rod** | 内撑拉杆 | 大截面风管内部拉杆支撑 |
| **Access Door / Panel** | 检修门 / 检查口 | 管道清洗、防火阀与风阀检修用密封口 |
| **Turning Vanes** | 导流叶片 / 导流弯头叶片 | 弯头内部用于减小气流阻力与涡流的导风叶片 |
| **Spigot** | 承口短接 / 插接支管短管 | 主风管引出支管的接合接头 |
| **Flexible Joint** | 软接头 / 柔性短管 | 风机、空调箱进出口减振降噪帆布/防火软接 |
| **Hangers and Supports** | 支吊架 | 包含吊杆（Threaded Rod）、横担（Trapeze）等承重结构 |

## 2. BESA DW/143 风管漏风量测试专用术语

| 英文原词 (English) | 规范中文译名 (Chinese) | 行业释义 / 说明 |
| :--- | :--- | :--- |
| **Ductwork Leakage Testing** | 风管漏风量测试 | 验证风管系统气密性的承压测试 |
| **Permissible Leakage Rate ($q_{vL}$)**| 允许漏风率 | 规范允许的最大漏风限量，单位为 $\text{L/(s}\cdot\text{m}^2\text{)}$ |
| **Class A Leakage Formula** | A 级允许漏风率计算公式 | $0.024 \times p^{0.65}\quad [\text{L/(s}\cdot\text{m}^2\text{)}]$ |
| **Class B Leakage Formula** | B 级允许漏风率计算公式 | $0.009 \times p^{0.65}\quad [\text{L/(s}\cdot\text{m}^2\text{)}]$ |
| **Class C Leakage Formula** | C 级允许漏风率计算公式 | $0.003 \times p^{0.65}\quad [\text{L/(s}\cdot\text{m}^2\text{)}]$ |
| **Class D Leakage Formula** | D 级允许漏风率计算公式 | $0.001 \times p^{0.65}\quad [\text{L/(s}\cdot\text{m}^2\text{)}]$ |
| **Static Gauge Pressure ($p$)** | 静压表压 ($p$) | 测试管段内的正/负工作压强，单位为 Pa |
| **Surface Area of Ductwork ($A$)** | 风管表面积 ($A$) | 被测受检管段的外表面展开总面积，单位为 $\text{m}^2$ |
| **Test Section** | 测试管段 | 用堵头/气囊临时隔离出的待检风管区段 |
| **Orifice Plate** | 孔板流量计 | 漏风测试仪中测量泄漏风量的核心节流元件 |
| **Test Rig / Leakage Tester** | 漏风量测试仪 | 包含风机、调压变频器、微压差计与流量喷嘴的测试整机 |
| **Blanking Off / Temporary Sealing** | 封堵 / 临时密封 | 用临时端盖、盲板或充气气囊密封管端进行测试 |

## 3. ISO 15138 海上石油平台与海洋工程 HVAC 术语

| 英文原词 (English) | 规范中文译名 (Chinese) | 行业释义 / 说明 |
| :--- | :--- | :--- |
| **Offshore Production Installation** | 海上生产装置 / 海上平台 | 采油平台、FPSO、海上天然气终端等 |
| **Hazardous Area** | 危险区域 / 爆炸性危险环境 | 易燃易爆气体可能集聚的区域（Zone 0, Zone 1, Zone 2） |
| **Non-Hazardous Area** | 非危险区 / 安全区 | 生活区、中央控制室等安全建筑 |
| **Pressurization / Overpressure** | 正压维持 / 正压防爆 | 生活区和控制室相对外界保持正压（如 50 Pa），防止有毒有害或可燃气体侵入 |
| **Fire and Gas (F&G) System** | 火灾与气体监测报警系统 (F&G) | 联动触发风机停机与气密阀门关断的生命安全系统 |
| **A-60 / H-120 Fire Damper** | A-60 / H-120 级耐火风阀 | 海工最高等级防爆耐火风阀（H 级适用于烃类火灾） |
| **Blast Damper** | 抗爆阀 / 防冲击波风阀 | 能够承受外部爆炸冲击波超压（Blast Overpressure）的重型风阀 |
| **Air Handling Unit (AHU)** | 空气处理机组 (AHU) | 海工级空调箱（箱体通常要求 316L 不锈钢双层隔热） |
| **Droplet Separator / Mist Eliminator** | 汽水分离器 / 除雾百叶 | 进风口防止海水飞沫、高盐度雾气进入管系的高效气水分离装置 |
| **Marine Environment** | 海洋腐蚀环境 | 高湿度、高盐雾环境，对应 ISO 12944 C5-M / CX 腐蚀等级 |
| **Air Change Rate (ACH)** | 换气次数 (ACH) | 危险区域保证安全所必需的每小时换气次数 |

## 4. ASTM 材料与钣金规格标准

| 英文原词 / 编号 (English/Standard) | 规范中文译名 (Chinese) | 说明 / 牌号参考 |
| :--- | :--- | :--- |
| **ASTM A653 / A653M** | 镀锌/锌铁合金冷轧钢板标准 | 通风风管最常用的热镀锌板母材标准 |
| **ASTM A240 / A240M** | 铬及铬镍不锈钢板标准 | 304、316L 等耐蚀风管与防火阀叶片用不锈钢 |
| **ASTM A15 / A...** | 钢制板材与棒材材料规范 | 钣金、支撑型钢及紧固构件常用标准 |
| **Galvanized Coating Designation** | 镀锌层重量标识 | 如 `G90`（美制 $0.90\text{ oz/ft}^2$）或 `Z275`（公制 $275\text{ g/m}^2$） |
| **Tensile Strength** | 抗拉强度 | 板材断裂极限强度 ($R_m$) |
| **Yield Strength** | 屈服强度 | 板材塑性屈服点 ($R_e / R_{p0.2}$) |
| **Elongation** | 断后伸长率 | 衡量咬口加工冷弯塑性的关键指标 |
| **Mill Test Certificate (MTC)** | 钢厂材质证明书 / 质保单 | 符合 EN 10204 3.1 级别的材质追踪证明 |
