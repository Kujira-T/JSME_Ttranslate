# JSME & 机械工程专业术语对照表 (Mechanical Engineering Glossary)

本词汇表汇集日本机械学会（JSME）、ASME、JIS 与中国国家标准（GB/T）中的高频专业术语。

---

## 1. 材料力学与强度评价 (Mechanics of Materials & Strength Evaluation)

| 日文术语 (Kanji/Kana) | 英文术语 (English) | 规范中文译名 (Chinese) | 备注说明 |
| :--- | :--- | :--- | :--- |
| 応力 (おうりょく) | Stress | 应力 | 内力分布密度 |
| ひずみ | Strain | 应变 | 变形率 |
| 許容応力 (きょようおうりょく) | Allowable Stress | 许用应力 | 设计允许的最大安全应力 |
| 降伏点 / 耐力 | Yield Point / Proof Stress | 屈服点 / 屈服强度 | 塑性变形起始应力 |
| 引張強さ | Tensile Strength | 抗拉强度 | 最大拉伸破坏应力 |
| 疲労限度 / 疲労強度 | Fatigue Limit / Strength | 疲劳极限 / 疲劳强度 | 交变载荷下的耐久极限 |
| 破壊力学 (はかいりきがく) | Fracture Mechanics | 断裂力学 | 含缺陷结构的力学分析 |
| 応力拡大係数 | Stress Intensity Factor ($K$) | 应力强度因子 | 裂纹尖端应力场强弱 |
| 限界き裂長さ | Critical Crack Length | 临界裂纹长度 | 失稳扩展的临界尺寸 |
| 減肉 (げんにく) | Wall Thinning / Metal Loss | 壁厚减薄 / 腐蚀减薄 | 配管内壁冲刷或腐蚀导致的厚度损失 |
| 健全性評価 (けんぜんせい) | Integrity Assessment | 结构完整性评估 | 包含缺陷设备的适用性评价 (FFS) |

---

## 2. 管道、阀门与压力容器 (Piping, Valves & Pressure Vessels)

| 日文术语 (Kanji/Kana) | 英文术语 (English) | 规范中文译名 (Chinese) | 备注说明 |
| :--- | :--- | :--- | :--- |
| 配管 (はいかん) | Piping / Pipe | 管道 / 配管 | 工艺与动力管系 |
| 継手 (つぎて) | Joint / Fitting | 接头 / 管件 | 焊接接头、法兰接头等 |
| 溶接部 (ようせつぶ) | Welded Joint / Weldment | 焊接接头 / 焊缝区 | 包含焊缝、熔合线及热影响区 |
| 熱影響部 (HAZ) | Heat-Affected Zone (HAZ) | 热影响区 (HAZ) | 母材金相受焊接热循环影响的区域 |
| 突合せ溶接 | Butt Welding | 对接焊接 | 常用高质量管道焊接方式 |
| 隅肉溶接 | Fillet Welding | 角焊 / 角接焊接 | 结构加固与承插焊常见 |
| フランジ | Flange | 法兰 | 可拆卸管路连接组件 |
| 弁 (べん) / バルブ | Valve | 阀门 | 截止阀、闸阀、止回阀等 |
| 耐圧試験 (たいあつしけん) | Hydrostatic / Proof Test | 水压试验 / 耐压试验 | 验证承压承载能力的静态压力测试 |
| 気密試験 (きみつしけん) | Pneumatic / Tightness Test | 气密性试验 | 检查微小气体泄漏 |

## 3. 检查、检验与无损检测 (Inspection & NDT)

| 日文/英文缩写 | 完整英文 (English) | 规范中文译名 (Chinese) |
| :--- | :--- | :--- |
| **NDT / NDE** | Non-Destructive Testing / Evaluation | 无损检测 / 无损评价 |
| **VT** | Visual Testing | 目视检测 |
| **PT** | Penetrant Testing (Liquid Penetrant) | 渗透检测 (着色探伤) |
| **MT** | Magnetic Particle Testing | 磁粉检测 |
| **UT** | Ultrasonic Testing | 超声检测 |
| **RT** | Radiographic Testing | 射线检测 (X射线/γ射线) |
| **ET** | Eddy Current Testing | 涡流检测 |
| **PWHT** | Post-Weld Heat Treatment | 焊后热处理 |
| **熱エージング** | Thermal Aging | 热老化 |
